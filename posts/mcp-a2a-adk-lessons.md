Being first isn't impressive — being documented first is.

Every new AI agent protocol (MCP, A2A, Google ADK) is a coordination primitive. East Africa should be building on them within weeks of global availability — not years.

- mpesa-mcp: first East African financial API in the MCP ecosystem
- kenya-a2a: first A2A implementation for East Africa
- kenya-adk: first Google ADK deployment for East Africa

All open-source. All citeable. [gabrielmahia.github.io](https://gabrielmahia.github.io)
